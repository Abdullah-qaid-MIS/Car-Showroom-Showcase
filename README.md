## 📖 نبذة عن النظام (Overview)

صُمم **نظام إدارة معرض السيارات** ليكون الحل التقني الأمثل لتنظيم سير العمل داخل معارض السيارات. يقدم النظام بيئة تفاعلية حديثة تعتمد على بنية الصفحة الواحدة (SPA) لضمان السرعة والأداء العالي. يغطي النظام كافة الجوانب الإدارية ابتداءً من تسجيل المشتريات وإدارة المخزون، وصولاً إلى إتمام عمليات البيع واستخراج التقارير المالية الدقيقة.

---

## ✨ الخصائص والمميزات الرئيسية (Core Features)

- 🚗 **إدارة المخزون الشاملة:** إضافة السيارات الجديدة بكل تفاصيلها (الموديل، اللون، السعر، حالة السيارة)، وتتبع السيارات المتاحة للبيع أو المباعة بدقة.
- 📄 **نظام العقود والمبيعات:** إنشاء فواتير وعقود بيع للعملاء بشكل آلي، مع أرشفة كاملة لجميع العقود للرجوع إليها مستقبلاً.
- 🛒 **إدارة المشتريات:** توثيق فواتير الشراء وتسجيل المبالغ المدفوعة للموردين وتجار السيارات.
- 👥 **إدارة العملاء والموردين:** قاعدة بيانات متكاملة لحفظ معلومات العملاء والموردين لتسهيل التواصل ومتابعة التعاملات المالية.
- 📊 **الإدارة المالية والتقارير:** لوحة تحكم ديناميكية تحتوي على رسوم بيانية (Charts) تعرض بوضوح (الأرباح الصافية، حركة المبيعات والمشتريات، السيولة النقدية المتوفرة).
- 🔐 **إدارة الموظفين والصلاحيات:** نظام أمني متقدم يتيح للمدير إضافة الموظفين وتخصيص صلاحيات دقيقة لكل مستخدم (مثل إيقاف صلاحية الحذف أو التعديل).
- 🌓 **تخصيص واجهة المستخدم:** دعم كامل للوضع الليلي والنهاري (Dark/Light Mode)، بالإضافة إلى دعم تعدد اللغات لتجربة استخدام مخصصة.

---

## 🛠️ التقنيات وبيئة التطوير (Tech Stack)

### الواجهة الأمامية (Frontend)
- **لغات التصميم والبرمجة:** HTML5, CSS3, Vanilla JavaScript.
- **الهيكلية:** تم البناء بأسلوب (Single Page Application) لتنقل سلس وسريع بين الأقسام دون الحاجة لإعادة تحميل الصفحة.

### الواجهة الخلفية (Backend)
- **لغة البرمجة:** PHP.
- **بناء الواجهات (API):** تم تطوير مجموعة من واجهات برمجة التطبيقات (APIs) الآمنة للتعامل مع العمليات وإدارة تدفق البيانات.

### قاعدة البيانات (Database)
- **النوع:** MySQL.
- **التخزين:** حفظ هيكلي متكامل وآمن لجميع سجلات المعرض والعقود والمستخدمين.

## 🚀 دليل التثبيت والتشغيل المحلي (Installation Guide)

للاستمتاع بتجربة النظام على خادمك المحلي، يرجى اتباع الخطوات البسيطة التالية:

1. **تحميل الخادم المحلي:** قم بتثبيت برنامج مثل **XAMPP** أو **WAMP**.
2. **نسخ المشروع:** انقل مجلد المشروع `Car-ShowroomProject` إلى مجلد `htdocs` (في حال استخدام XAMPP).
3. **تهيئة قاعدة البيانات:**
   - افتح لوحة التحكم `phpMyAdmin` (عادة عبر الرابط `http://localhost/phpmyadmin`).
   - أنشئ قاعدة بيانات جديدة.
   - قم باستيراد الملف المرفق `car_showroom.sql` لتهيئة الجداول.
4. **تحديث إعدادات الاتصال:** تأكد من مطابقة اسم قاعدة البيانات وكلمة المرور في ملفات الاتصال بقاعدة البيانات داخل مجلد `api/`.
5. **تشغيل النظام:** افتح المتصفح وتوجه إلى الرابط:
   `http://localhost/Car-ShowroomProject/login.html`
